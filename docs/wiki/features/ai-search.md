# AI 보육원 검색

> 상태: 계획 중 (MVP 이후)

## 목적
사용자가 자연어로 질문하면 조건에 맞는 보육원을 답변과 목록으로 보여준다. 목록에서 바로 보육원 상세 정보로 이동할 수 있다.

## 요구사항
- [ ] 자연어 질문을 받아 답변 문장과 보육원 목록을 함께 응답한다
- [ ] 목록의 각 항목을 누르면 해당 보육원 상세 화면으로 이동한다
- [ ] 사용자 위치 기준 거리 조건을 처리한다
- [ ] LLM은 DB에 직접 접근하지 않는다

## 단계별 계획
| 단계 | 방식 | 처리하는 질문 예시 |
|---|---|---|
| 1 | [Function Calling](../tech/function-calling.md) | "가까운 곳 중 아동 30명 이하, 기독교 재단 소속 보여줘" (조건이 정해진 질문) |
| 2 | [RAG](../tech/rag.md) + pgvector | "음악 프로그램을 운영하는 곳 있어?" (자유 텍스트에서 찾아야 하는 질문) |
| 3 | 두 방식 결합 | 조건과 의미 검색이 섞인 질문 |

## 필요한 데이터 (확인 필요)
- 보육아동 인원, 종교/재단 소속: 공공데이터에 있는지 확인해야 한다. 없으면 직접 수집하거나 보육원이 입력하는 기능이 필요하다.
- 소개글, 운영 프로그램, 필요 물품: RAG 단계에서 필요하다. 출처 미정.

## 사용 기술
- 서버: [Spring Boot](../tech/spring-boot.md) + Spring AI (버전은 착수할 때 확정)
- DB: [PostgreSQL](../tech/postgresql.md) (+ pgvector)
- LLM, 임베딩 모델: 미정
