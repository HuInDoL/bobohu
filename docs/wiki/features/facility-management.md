# 시설 담당자 정보 관리

> 상태: 계획 중

## 목적
보육원 세부 정보(아동 인원, 소속, 소개, 필요 물품 등)는 **시설 담당자(원장 등)가 직접 입력하고 관리**한다. 운영자가 모든 데이터를 모으는 것은 불가능하고, 그래서도 안 된다. 정보의 정확성과 책임은 시설에 있다.

## 역할
| 역할 | 할 수 있는 일 |
|---|---|
| 일반 사용자 | 지도 보기, 검색, (이후) 후원 |
| 시설 담당자 | 인증받은 자기 시설의 정보 입력과 수정 |
| 관리자 | 담당자 인증 승인과 거절, 부적절한 정보 관리 |

## 요구사항
- [ ] 담당자 회원가입과 로그인
- [ ] 지도에 있는 시설에 대해 "내 시설로 등록 요청" (증빙 서류 첨부)
- [ ] 관리자가 요청을 확인하고 승인하거나 거절
- [ ] 승인된 담당자만 해당 시설 정보 수정 가능
- [ ] 시설 정보에 마지막 수정일 표시
- [ ] 목록에 없는 시설은 신규 등록 요청 가능 (관리자 승인)

## 입력 항목 (초안)
| 구분 | 항목 | 형식 | 용도 |
|---|---|---|---|
| 조건 검색용 | 아동 인원, 정원 | 숫자 | [Function Calling](../tech/function-calling.md) 검색 조건 |
| | 종교, 소속 재단 | 선택 목록 (+ 기타 직접 입력) | Function Calling 검색 조건 |
| | 연락처, 운영 시간 | 정해진 형식 | 상세 화면 |
| 의미 검색용 | 소개글, 운영 프로그램, 필요 물품 | 자유 텍스트 | [RAG](../tech/rag.md) 검색 대상 |

## 개인정보 원칙
- **아동 개인정보는 받지 않는다.** 이름, 사진, 사연, 생년월일처럼 아동을 식별할 수 있는 정보는 입력 항목에 두지 않는다. 아동 관련 정보는 인원 수 같은 **집계 정보만** 받는다.
- 이유: 아동 개인정보는 법적으로 특히 엄격하게 보호된다. 시설 아동은 신원이 노출되면 위험해질 수 있다.
- 자유 텍스트 입력란에 "아동 개인정보나 사진을 올리지 마세요" 안내를 표시한다.
- 담당자의 증빙 서류는 인증 목적에만 쓰고, 접근을 관리자로 제한한다.

## 동작 흐름
```
담당자 가입 → 시설 선택 후 등록 요청 (+ 증빙 서류) → 관리자 검토 → 승인
   → 담당자 권한 부여 → 시설 정보 입력과 수정 → 지도와 검색에 반영
```

## 사용 기술
- [Spring Boot](../tech/spring-boot.md) + Spring Security (역할 기반 권한 관리)
- [PostgreSQL](../tech/postgresql.md)
- 증빙 파일 저장소: 미정

## 확인할 것

- [ ] 증빙 서류 보관 기간과 파기 정책
- [ ] 한 시설에 담당자를 여러 명 둘 수 있게 할지
